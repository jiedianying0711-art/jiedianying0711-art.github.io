问题

02 / MY ROLE

本人职责

关键设计

数据仓库与数据治理

拉通业务库、日志、第三方数据（ODS），设计落地统一 ETL 流程，参与构建 TB 级 DWD；设计 DWS 主题/星型模型，梳理清洗规范与质量规则。

据产品经理简历 · 大疆 BI

指标体系与 BI 可视化

构建近 1000 个通用业务指标并统一口径；负责一级部门数据大屏与各业务线驾驶舱，内置近 20 个通用看板，支持逐层下钻定位问题。

据产品经理简历 · 大疆 BI

自助分析

基于统一指标体系提供自定义指标、组合分析与灵活看板，使一线业务团队自主搭建分析视图。

据产品经理简历 · 大疆 BI

数据 API 与权限
