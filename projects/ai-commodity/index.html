AI 商品智枢
从金融研究问题，到可运行的产品体系。

这是本人的独立产品实践项目，不是企业产品官网：面向商品期货研究与交易决策支持，围绕“数据—研究—建模—监控—复盘”组织功能，由 Web 门户与 PC 多 AI 工作台分担展示与复杂任务执行。

金融数据产品Agent 工作流研究与建模Web + PC 双端
01 / PROBLEM

问题

商品研究资料分散、数据重复更新、结论难以复用，且缺少持续验证机制；“人工读研报—更新数据—形成观点—撰写周报”的方式无法沉淀为可持续运行的研究能力。

02 / MY ROLE

本人职责

本人独立承担产品规划与体系设计：五大业务体系划分、Web/PC 双端分工、数据底座与指标体系、Agent 研究工作流编排、质量规则与复盘闭环。

03 / KEY DESIGN

关键设计

划分数据、研究、建模、监控、交易与复盘五大业务体系，明确各体系的功能边界与共享底座。

04 / EVIDENCE

交付及证据

六张核心产品图完整总览（已授权展示，含定位、五大体系、双端协同、技术架构、Agent 工作流与 EG2610 案例）。

05 / BOUNDARY

边界

实盘交易网关禁用，不提供真实自动下单能力。

01 / PRODUCT PROBLEM

业务问题与产品目标

研究人员需要反复收集行情、产业数据与资讯；研究结论难以复用，模型与持续监控之间缺少清晰的协作方式。产品围绕可追溯数据、可复用研究流程和持续检验机制建立统一工作环境，把一次性研究结论沉淀为可持续验证、持续迭代的研究能力。

02 / PRODUCT MAP

五大业务体系

体系划分来自本人规划设计，功能摘要与已授权的六合一产品图组一致。

DATA

数据

行情与期货结构、产业链供需、宏观资讯采集、指标口径与数据管理、多源数据 API。

RESEARCH

研究

品种专题分析、AI 日报与研究摘要、深度研报、多 AI 研究会议、知识沉淀与历史复用。

MODELING

建模

期货理论定价、期权策略与情景分析、技术指标与因子、量化策略验证、时序分析与预测。

MONITOR

监控

每日机会发现、盘中异动预警、期现资讯监控、舆情信号、Bark / 邮件通知。

REVIEW

交易与复盘

模拟验证与 AI 成绩单、交易记录上传、绩效与回撤检查、AI 复盘；交易接口禁用并明确边界。

03 / WEB × PC

Web 门户与 PC 工作台分工

WEB 研究门户

展示与管理

品种与指标、研究阅读、资讯监控、页面管理；面向轻量使用与成果浏览。

PC 多 AI 工作台

深度研究执行

多 AI 研究、任务编排、研究验证、成果沉淀；面向专业任务与复杂执行。

04 / AGENT WORKFLOW

多 Agent 研究工作流

人机协同闭环：AI 从一次性问答升级为可持续运行的研究助手；支持独立完整研究与多人专业分工两种模式，统一经过证据互检与反方验证。

01 / ASK

研究员提问

提出问题与主观判断，定义数据约束与输出要求。

02 / PLAN

GPT 协助拆解

任务分解、模型选择与状态管理，形成可执行研究计划。

03 / RUN

Agent 执行

数据 / 工具 Agent 执行，生成数据、图表与报告。

04 / REVIEW

人工审核迭代

研究员审核、再讨论，更新判断与监控规则。

工作流配套 Prompt 与 SOP 驱动、故障自动接力、上下文交接与研究结果沉淀机制；每期结果由研究员审核后纳入监控规则。

06 / MY CONTRIBUTION
